# Atomic Finds ATX
## Product Taxonomy, Tags, Keywords & Curator Strategy

**Purpose:** Create a scalable product-classification system that supports customer browsing, on-site filtering, SEO, merchandising, and the whimsical Curators experience.

---

## 1. Recommended Product Structure

Use four layers on every product. This protects the functional catalog structure while allowing Atomic Finds’ personality to appear throughout the customer journey.

| Layer | Purpose | Example |
|---|---|---|
| **Product type** | The primary functional classification—what the item is | Coffee Table |
| **Room / collection** | Where or how a shopper uses the item | Living Room |
| **Attribute tags** | Searchable material, era, style, feature, or use descriptors | Rattan, 1970s, Boho |
| **Curator field** | The character guiding the item’s story and experience | Daisy |

### Guiding rule

Assign **one product type** and **one Curator** per product. Use tags and collections for everything else.

Do not use **Vintage Lounge** as a product type. Use **Living Room** as the shopper-facing room category and use **Vintage Lounge** as a branded collection or merchandising theme.

## 6. The Curators System

The Curators should function as playful product guides, while **Jennyfer remains the sole real-life owner, source, and restorer** in brand copy.

### Curator Assignment Model

| Curator | Specialty | Assign To | Required Tag |
|---|---|---|---|
| **Daisy** | Relaxed, comfortable, centerpiece seating | Lounge chairs, accent chairs, peacock chairs, swivel chairs, hero seating | `curator-daisy` |
| **Milo** | Craftsmanship, materials, weave, restoration | Rattan, wicker, bamboo, well-built tables, shelving, restoration-forward finds | `curator-milo` |
| **Tatiana** | Drama, silhouette, conversation-starting design | Sculptural furniture, arched shelves, unusual tables, bold statement pieces | `curator-tatiana` |
| **Malibu** | Hosting, gathering, social spaces | Bar carts, dining tables, dining chairs, dining sets, entertaining storage | `curator-malibu` |

### Customer Experience Placement

- **Product cards:** Small Curator badge, e.g., “Daisy’s Lounge Pick.”
- **Product detail pages:** Character illustration, a short Curator line, and optional “why I picked it” micro-story.
- **Cart:** A compact sendoff such as “Malibu says your next golden-hour gathering is handled.”
- **Post-purchase:** Use the assigned character in a thank-you or care-tip message.
- **Collection pages:** Create optional Curator-led discovery pages later, such as “Malibu’s Hosting Orbit” or “Daisy’s Favorite Seats.”

## 8. CMS Fields to Create

| Field | Type | Use |
|---|---|---|
| `product_type` | Single-select | One primary functional product classification |
| `room_collection` | Multi-select | Browsing categories and room-based filters |
| `materials` | Multi-select | Rattan, bamboo, wicker, glass, wood, etc. |
| `style_era` | Multi-select | Vintage, 1970s, mid-century, boho, tiki, etc. |
| `features` | Multi-select | Rolling, swivel, glass-top, arched, set-of-4, etc. |
| `curator` | Single-select | Daisy, Milo, Tatiana, or Malibu |
| `curator_line` | Short text | Character-specific product dialogue |
| `restoration_note` | Rich text / long text | Condition, repairs, craftsmanship, care, and provenance |
| `local_pickup` | Boolean | Pickup eligibility |
| `seo_primary_keyword` | Short text | One focused target phrase per product |

---

## 9. Launch Checklist

1. Set one product type for every item.
2. Add each item to one or more customer-facing collections.
3. Apply 6–10 relevant controlled tags per product.
4. Assign exactly one Curator to every product.
5. Write one curator-specific line for the product page.
6. Select one primary SEO keyword phrase per product.
7. Add product-specific descriptive alt text to every image.
8. Audit tags monthly to merge duplicates and prevent tag sprawl.

---

## Final Recommendation

Launch the taxonomy as a straightforward catalog system first; use the Curators as the memorable emotional layer on top. That creates clean filters and scalable SEO while making Atomic Finds feel distinct at every touchpoint—from product discovery to checkout.
